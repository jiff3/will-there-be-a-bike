# Security reporting

Controls and limitations: [security runbook](docs/SECURITY.md), [deployment](docs/DEPLOYMENT.md).

No hosted service or maintainer security mailbox is configured. Owners should enable GitHub private vulnerability reporting before publication and publish a contact/support policy before public operation. Use that private channel when available; never expose credentials, user records or exploit payloads in public issues.

No independent penetration test, verified email, password recovery or MFA is claimed. Production requires HTTPS, restricted DB credentials, trusted artifacts, backups and monitoring.
