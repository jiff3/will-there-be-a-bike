# Security reporting

Controls and limitations: [security runbook](docs/SECURITY.md), [deployment](docs/DEPLOYMENT.md).

Report suspected vulnerabilities through [GitHub's private reporting channel](https://github.com/jiff3/will-there-be-a-bike/security/advisories/new), which is enabled for this repository. Include reproduction steps and affected versions, but do not include real passwords, tokens or user records. Never post exploit payloads or sensitive details in public issues.

No hosted service, separate security mailbox or guaranteed response time is configured. General bugs and feature requests belong in repository issues; sensitive security reports belong in the private channel above.

No independent penetration test, verified email, password recovery or MFA is claimed. Production requires HTTPS, restricted DB credentials, trusted artifacts, backups and monitoring.
